# lib 작업 규칙

이 문서는 제품 코드의 모듈 경계를 정한다. 루트 `AGENTS.md`의 영구 무료 약속과 공통 규칙이 우선한다.

- `src/core/`: analyzer에 독립적인 ID, 그래프, 설정, 캐시 경계. 다른 제품 모듈에 의존하지 않는다.
- `src/index/`: `package:analyzer`를 import할 수 있는 유일한 모듈. analyzer 타입을 밖으로 노출하지 않고 core 타입으로 변환한다.
- `src/analysis/`: core 그래프만 질의한다. 소스나 analyzer를 직접 읽지 않는다.
- `src/export/`: 정렬된 core 결과를 결정론적으로 직렬화한다. 판정을 새로 만들지 않는다.
- `src/cli/`: 인자, 출력, 종료 코드 `0/1/2/64`만 책임진다. 분석 의미는 하위 모듈에 둔다.

모든 판정은 근거와 한계를 동반한다. 삭제 가능 판정이나 자동 삭제 API를 추가하지 않는다. 캐시는 성능 계층일 뿐이며 켜거나 꺼도 같은 그래프를 만들어야 한다.
