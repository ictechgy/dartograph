# 문서 규칙

[루트 규칙](../AGENTS.md)을 따른다. 구현된 기능·계획·측정 결과를 서로 구분한다.

- PRD.md: 제품 목적·영구 무료 약속·범위. 미구현 기능은 미래 범위나 확인 필요로 표시한다.
- PLAN.md: 단계와 검증 순서. 과거 실행 환경이나 완료 기록을 현재 상태로 단정하지 않는다.
- RESEARCH.md: 확인된 사실과 미확인 가설. 외부 사실에는 날짜와 근거를 남기고 GLM 답변만으로 사실을 확정하지 않는다.
- DECISION-analyzer.md: 실험 조건·결정·근거. 새 결과는 과거 기록을 덮어쓰지 말고 조건을 구분해 추가한다.
- USAGE.md: 실제 설치·명령·출력·종료 코드. CLI·테스트·README·CHANGELOG와 일치시킨다.
- compare의 관측 차이, 소스 단위 한계, 어휘적 bridge 이름을 인과 증명·삭제 안전성·컴파일러 USR로 표현하지 않는다.
- 로컬 자매 저장소 경로를 독자의 필수 선행 조건으로 만들지 않는다. 공개 계약 링크나 설치 조건을 제공한다.
- 문서 변경은 링크·Markdown 구조·명령의 실제 존재·버전 정합성을 확인한다. 문서를 Dart 소스로 포맷하지 않는다.
